Signal Watch is an educational demo. Traffic is synthetic by default — use “Generate new sample traffic” to reshuffle it, or load your own resolver log as JSON (see data/sample-log-schema.json for the expected fields). Detection is purely heuristic: entropy, label length, charset shape, query-type mix, subdomain uniqueness, and query rate are combined into a single 0–100 score per domain. It is a learning tool, not a production intrusion-detection system — tune thresholds against your own baseline before relying on it operationally.
